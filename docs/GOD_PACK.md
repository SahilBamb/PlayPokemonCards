# Fantasy God Pack

The Card Opener supports a deliberately fictional Base Set pack for recording
content. This is not historical Base Set collation. Ordinary packs and existing
seeds keep their usual mix. It adds no rewards to the card battle game.

Open `/card-opener?pack=god&seed=GOD-MAGIKARP-6`, choose Base Set, confirm the
purchase and tear the wrapper. The explicit `pack=god` query enables this mode
only for Base Set. Other sets use their ordinary collation. The seed selects
eleven unique holos, orders the first ten by available market estimates, and
keeps Charizard last. Refresh preserves the pack type and opened cards.

Gold rays, sparkles, a shimmering GOD PACK title and the subtitle
“Fantasy Base Set pack” appear as the cards emerge and remain during reveals.
The title has reserved space above the stack, including on phones, and all
effects respect the existing reduced motion controls. Wallet, inventory and
sale behavior use the existing simulated accounting.

The recorded pack is Hitmonchan, Magneton, Ninetales, Zapdos, Chansey, Gyarados,
Raichu, Alakazam, Venusaur, Blastoise and Charizard. Its October 25 price snapshot
totals $1,723.11. Those are cached estimates, not real rewards or guaranteed prices.
